Engage360 uses this signal to trigger highly personalized and timely WhatsApp messages—reminding the user to complete their purchase, offering support, or applying urgency with limited-time offers. This real-time re-engagement increases the likelihood of recovering sales that would have otherwise been lost.

You can also tailor flows based on payment method, cart value, or product category to increase message relevance and recovery rates.
</Expandable>

  1. Offer Discount Coupons: Provide instant discounts (e.g., ₹30–₹50 off) for customers who choose prepaid at checkout or after placing a COD order.

<Expandable title="How is ROAS calculated?" default-open="false">
  ROAS (Return on Ad Spend) in Engage360 is calculated using the following formula:
  ROAS = Attributed Revenue ÷ Campaign Spend
  Attributed revenue is determined using a last interaction attribution model. This means revenue is assigned to the most recent eligible campaign or journey message the customer received within a defined attribution window.
  Key Rules for Attribution:

  1. Last Interaction Basis: The system attributes the order to the last message (campaign or journey) sent to the user within the attribution window.

  2. Channel Priority: If the user received messages from multiple channels, attribution is based on the following hierarchy:
     WhatsApp > SMS > Email

  3. Campaign vs Journey Priority: If a user receives messages from both a campaign and a journey, the campaign takes precedence, even if the journey message was more recent.

  4. Attribution Window: This is the period after a message is sent, within which an order must be placed for it to be attributed. The window is configurable for each channel. For Whatsapp and email it's 14 days, for sms it's 2 days.

  5. Delivery/Read Status Requirement:
     Attribution occurs only if the message was:
     -> Delivered (for SMS)
     -> Read (for WhatsApp and Email)

  6. No On-Site Attribution: Orders placed without any prior message interaction (such as direct website visits) are not attributed to Engage360 campaigns or journeys.
     This method ensures ROAS reflects the revenue influenced by actual user interaction with Engage360 communications.
</Expandable>

  6. Product or Source Not Tracked: For abandoned journeys, if your website or checkout doesn’t have tracking code (JS SDK or webhook), events like “add to cart” or “begin checkout” won’t register.
     Journeys rely on accurate event tracking and message eligibility. Always check integration status, opt-in presence, and event flow in the Activity Logs. Shiprocket Checkout users must ensure the integration toggle is ON for journey triggers to work.
</Expandable>
