## What can I do on Shiprocket Trends?

You can explore dashboards for Orders, Buyers, RTO, Categories, and Cities. The platform also features an Ask AI tool that lets you query data using natural language.

---

## What is the Ask AI feature in Shiprocket Trends?

Ask AI is a natural language query interface in Shiprocket Trends that allows you to:
1. Ask questions in plain English (e.g., "What are the top trending products in Mumbai this month?")
2. Get instant data-driven answers
3. Explore trends without needing technical analytics skills

---

## What dashboards are available in Shiprocket Trends?

Shiprocket Trends dashboards include:
1. Orders Dashboard: Order volume trends by category, city, time
2. Buyers Dashboard: Buyer behavior, demographics, purchase patterns
3. RTO Dashboard: Return rates by category, pincode, courier
4. Categories Dashboard: Category-level performance and trends
5. Cities Dashboard: Geographic demand distribution
