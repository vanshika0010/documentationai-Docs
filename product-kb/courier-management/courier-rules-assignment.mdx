<AccordionGroup>
  <Accordion title="How to set courier priority rules in Shiprocket?">

Go to Settings >> Courier >> Courier Rules from the left menu. Click 'Add New Rule' to create rules based on parameters like channel, order amount, pincode, weight, payment type (COD/Prepaid), or product category. You can set priority order for couriers matching each rule.

  </Accordion>
</AccordionGroup>

<AccordionGroup>
  <Accordion title="How does auto courier assignment work?">

When you process an order, Shiprocket automatically recommends the best courier based on your configured rules, delivery performance data, and cost. If no rule matches, it falls back to the default recommendation engine.

  </Accordion>
</AccordionGroup>

<AccordionGroup>
  <Accordion title="Can I restrict specific couriers for specific channels?">

Yes. In Courier Rules, you can set rules that restrict or prioritize specific couriers for specific sales channels.

  </Accordion>
</AccordionGroup>
