  <Accordion title="How is volumetric weight calculated and how does it affect my shipping charges?">

Volumetric weight = (Length cm x Breadth cm x Height cm) / 5000. If this value is higher than the actual dead weight, the courier charges based on volumetric weight. For example, a 40x30x20 cm box = 24,000/5000 = 4.8 kg volumetric. If actual weight is 2 kg, you are billed for 4.8 kg.
