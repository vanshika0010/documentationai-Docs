## can i automatically assign a courier to a return order?

Yes, you can automatically assign a courier to a return order. Enable the auto-assign feature by navigating to Settings > Company Setup > Returns and toggle on 'Auto Assign Courier'. When enabled, Shiprocket automatically selects the best available courier partner for each return pickup based on serviceability, performance, and availability at the buyer's pincode.
