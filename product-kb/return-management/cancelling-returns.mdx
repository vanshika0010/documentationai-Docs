---

<AccordionGroup>
  <Accordion title="How to cancel a return order in Shiprocket?">

Go to Returns, find the return order, and click 'Cancel Return.' This is only possible before the courier has picked up the item. Once picked up, the return cannot be cancelled.

  </Accordion>
</AccordionGroup>

<AccordionGroup>
  <Accordion title="What happens if a return is cancelled?">

When a return is cancelled, the courier pickup request is withdrawn and no charges are applied for the return. The original order remains in its delivered status.

  </Accordion>
</AccordionGroup>
