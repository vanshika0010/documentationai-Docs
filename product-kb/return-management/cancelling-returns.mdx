## How to cancel a return order?

For the cancellation of a return order on Shiprocket panel follow the below steps:
* Go to "Returns" section of your Shiprocket panel.
* Select the return order that you wish to cancel.
* Click on Cancel Return.
* Give a reason for cancellation
* Click on confirm

---

## Can I cancel a return after pickup?

Once the return has been picked up by the courier, cancellation becomes difficult. Contact Shiprocket support immediately with the AWB number if you need to cancel a return that's already been picked up. Interception is not guaranteed.

---

## What happens after a return is cancelled?

After a return is cancelled:
1. The return order status changes to Cancelled
2. No courier pickup will be scheduled/completed
3. The buyer will need to initiate a new return if they still want to return
4. Any scheduled pickup will be cancelled with the courier

---

## Can the buyer cancel a return request?

Return cancellation depends on your return policy configuration. If buyer-initiated returns are supported, buyers may be able to cancel a return request through the tracking page before courier pickup.

---

## How to reject a return request on Shiprocket?

To reject a return request:
1. Go to Returns section
2. Find the pending return request
3. Click on Reject Return
4. Select the rejection reason
5. Confirm

The buyer will be notified about the rejection.

---

## What is the time limit to cancel a return order?

Returns can be cancelled before the courier picks up the item. After pickup, the return is in transit and interception is subject to courier cooperation.

---

## What happens to the refund if a return is cancelled?

If a return is cancelled before it's processed:
1. No refund is initiated
2. The original transaction remains unchanged
3. The buyer retains the item

If a refund was already processed and then the return is cancelled, contact Shiprocket support for assistance.
