## How to cancel a return order?

For the cancellation of a return order on Shiprocket panel follow the below steps:
* Go to "Returns" section of your Shiprocket panel.
* Select the return order that you wish to cancel.
* Click on Cancel Return.
* Give a reason for cancellation
* Click on confirm

---

## Can I cancel a return after the courier has picked it up?

Once a return has been picked up by the courier, cancellation is very difficult. You should:
1. Contact Shiprocket support immediately with the AWB number
2. Request interception with the courier
3. Note that interception is not guaranteed once the package is in transit

---

## What happens when a return is cancelled?

When a return is cancelled:
1. The return order status changes to 'Cancelled'
2. No pickup will be scheduled (if cancellation is before pickup)
3. The buyer retains the item
4. No refund is processed for the cancelled return
5. The seller can choose to reship the item or take no further action

---

## Can a buyer cancel a return request?

Buyers can cancel a return request through the Post-Ship tracking page before the courier is assigned for pickup. Once assigned, only the seller can cancel through the Shiprocket panel.

---

## How to reject a return request on Shiprocket?

To reject a return:
1. Go to Returns section
2. Find the pending return request
3. Click on the return order
4. Select 'Reject Return'
5. Provide rejection reason
6. Confirm
The buyer will be notified about the rejection.

---

## What is the cancellation window for a return order?

Returns can be cancelled before the courier is assigned for pickup. Once a courier is assigned and the pickup is scheduled, you must contact support for any cancellation attempts.

---

## Will there be any charges if I cancel a return order?

If the return is cancelled before pickup, no charges apply. If the courier has already picked up the return, reverse logistics charges may still apply. Contact Shiprocket support for clarification on specific cases.
