<AccordionGroup>
  <Accordion title="What is Quality Check (QC) for returns?">

QC (Quality Check) for returns is a process where returned products are inspected at the pickup point or warehouse to verify their condition before a refund or exchange is processed. Shiprocket supports QC-enabled return orders where couriers check the item before accepting the return.

  </Accordion>
</AccordionGroup>

<AccordionGroup>
  <Accordion title="How to enable QC for return orders?">

Go to Settings >> Returns from the left menu. Enable the QC toggle. When creating return orders, you can specify QC requirements and the courier will inspect the item before accepting the return.

  </Accordion>
</AccordionGroup>
