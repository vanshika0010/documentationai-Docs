## What is QC (Quality Check) in return management?

QC (Quality Check) in return management is the process of verifying the condition of returned products when they arrive back at the seller's warehouse. Sellers can configure QC settings to determine whether a returned item is in sellable condition or needs to be flagged.

---

## How to enable QC for returns on Shiprocket?

To enable QC for returns:
1. Go to Settings >> Returns Management
2. Find the QC Settings section
3. Enable QC for return orders
4. Configure QC parameters (condition check, quantity check, etc.)
5. Save settings

---

## What are the QC status options for returned items?

QC status options for returned items:
1. Good Condition: Item is sellable and can be restocked
2. Damaged: Item is damaged and cannot be resold
3. Wrong Item: Item returned is different from what was ordered
4. Incomplete: Item is returned without all components/accessories
5. Used: Item has been used by the buyer

---

## How to configure return QC settings on Shiprocket?

Return QC settings can be configured from:
1. Settings >> Returns Management >> QC Settings
2. Configure which checks to perform (image upload required, condition check)
3. Set pass/fail criteria
4. Configure actions based on QC outcome (restock, quarantine, etc.)

---

## Can I make image upload mandatory during return QC?

Yes. You can configure the QC settings to make image upload mandatory during the return receiving process. This provides visual proof of the returned item's condition.

---

## How does automatic return QC work on Shiprocket?

Automatic return QC allows setting rules that automatically determine the QC outcome based on predefined criteria. For example, if the return reason is 'wrong item', it can be automatically flagged for investigation.

---

## What happens to items that fail QC in returns?

Items that fail QC:
1. Are marked with the appropriate QC status (Damaged, Wrong Item, etc.)
2. Are typically quarantined separately from good stock
3. May be eligible for courier damage claims
4. Can be disposed, returned to vendor, or kept for scrap based on seller policy

---

## Can I dispute a return that doesn't meet QC standards?

Yes. If a returned item fails QC due to courier damage:
1. Document the damage with photos
2. Raise a dispute in the Shiprocket panel
3. Include QC photos and the return order details
4. Shiprocket will coordinate with the courier for claim

---

## What is the return window for buyers on Shiprocket?

The return window is set by the seller in their return policy. Sellers can configure the return window (e.g., 7 days, 15 days, 30 days) in their Shiprocket settings.

---

## How to set up return policy on Shiprocket?

Return policy configuration:
1. Go to Settings >> Returns Management
2. Set the return window (days from delivery)
3. Configure eligible return reasons
4. Set QC requirements
5. Configure refund/replacement rules
6. Save settings

---

## Does Shiprocket support photo-based QC for returns?

Yes. Shiprocket's return management supports photo-based QC where the receiving team must upload photos of the returned item as part of the QC process.

---

## How to handle returns where the buyer has misused the product?

For returns where misuse is evident during QC:
1. Mark the QC status as 'Damaged/Used'
2. Document with photos
3. Based on your return policy, you may decline the return
4. Contact the buyer with the QC findings
5. Raise a dispute if needed

---

## What is grading in return QC?

Grading categorizes returned items into quality tiers:
* Grade A: Like new, sellable as new
* Grade B: Minor cosmetic issues, sellable as refurbished
* Grade C: Significant issues, not resalable

Grading helps in determining the appropriate disposition for returned inventory.

---

## Can I configure different QC rules for different product categories?

Return QC rules can be configured based on your specific business requirements. Contact Shiprocket support or check Settings >> Returns Management for category-specific QC configuration options.

---

## How to view return QC history on Shiprocket?

Return QC history is available in the Returns section of your Shiprocket panel. Filter by return order ID, status, or date range to view QC records for specific returns.
