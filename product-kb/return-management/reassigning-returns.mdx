## How to reassign a return order?

Please follow the steps below to re-assign a return order on Shiprocket:
* Go to the 'Returns' tab in the left panel.
* Click on three dots next to the return order you want to reassign.
* Select "Reassign Order" from the dropdown menu.
* Select the courier partner and the service you want to reassign to.
* Click on 'Reassign'.

---

## How to enable auto-assign courier for returns?

Yes, you can automatically assign a courier to a return order. Enable the auto-assign feature from Settings >> Returns >> Auto-assign Courier. When enabled, the system automatically selects the best available courier for each return pickup based on serviceability and performance.
