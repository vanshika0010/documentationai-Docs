## What is auto-assign for return courier on Shiprocket?

Auto-assign automatically selects the best courier partner for processing return pickups based on availability, serviceability, and performance at the buyer's pincode.

---

## How to manually reassign a return courier on Shiprocket?

To manually reassign a return courier:
1. Go to Returns section
2. Find the specific return order
3. Click on Reassign Courier
4. Select the new courier from available options
5. Confirm

Note: Reassignment is only possible before the courier picks up the return.
