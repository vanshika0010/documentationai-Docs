<AccordionGroup>
  <Accordion title="How to create a return order in Shiprocket?">

Go to Returns >> Create Return from the left menu. Enter the original order ID or AWB number, select the return reason, choose the pickup address (buyer's address), and select a courier. Confirm to create the return order.

  </Accordion>
</AccordionGroup>

<AccordionGroup>
  <Accordion title="What return modes does Shiprocket support?">

Shiprocket supports: Reverse Pickup (courier picks up from buyer), Self-Ship Return (buyer ships back via any courier), and Exchange (replacement sent while return is collected).

  </Accordion>
</AccordionGroup>
