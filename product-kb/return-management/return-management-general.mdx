## How to edit and customize refund settings?

* Please follow the steps below to edit and customize refund settings: 
   * Go to Settings and click on the Returns & Exchanges Tab.
   * Under Refund Settings, you'll see the options available for Shiprocket's refund settings.
   * Click on the Add Refund Mode button on the right side.
   * From the pop-up, select the Refund Type (Bank Transfer, UPI, or Store Credit/Wallet).
   * Click on Save.

---

## What is Shiprocket Returns?

Shiprocket Returns is a complete reverse logistics solution that allows sellers to manage the entire return lifecycle:
1. Accept/reject return requests from buyers
2. Schedule return pickups via courier
3. Track reverse shipments in real-time
4. Perform QC on received returns
5. Process refunds or replacements
6. Handle exchange orders

---

## What are the modes of Refund I can offer to my customer for return orders?

* There are 4 modes of refund powered by Shiprocket:
   * Manual Refund - Manually process the refund outside Shiprocket
   * Shiprocket Wallet Credit - Credit the refund to buyer's Shiprocket wallet
   * Bank Transfer - Transfer to buyer's bank account
   * Store Credit - Credit to buyer's store wallet

## How to set up return policy on Shiprocket?

To set up your return policy:
1. Go to Settings >> Company Setup >> Returns
2. Set the return window (days from delivery)
3. Configure eligible return reasons
4. Set QC requirements
5. Configure refund modes and timelines
6. Enable/disable buyer-initiated returns on Post-Ship page
7. Save settings

---

## Can I restrict returns for specific products?

Yes. You can mark specific products as non-returnable in your product catalog. Go to your product settings and enable the 'Non-Returnable' flag for products that cannot be returned.

---

## How does Shiprocket handle returns for COD orders?

For COD returns:
1. If COD was not yet remitted: No remittance occurs for that order
2. If COD was already remitted: RTO reversal amount is deducted from future COD remittances
3. Seller processes refund to buyer separately (bank transfer/store credit)

## What is the difference between return and RTO?

Return: Buyer initiates the return through the seller's return policy. Pickup is from buyer's location.

RTO (Return to Origin): Courier was unable to deliver the order. The shipment is automatically returned to seller. Not initiated by buyer.

---

## Can I offer partial returns on Shiprocket?

Yes. Buyers can select specific items to return from a multi-item order. When creating a return, select only the items being returned and their quantities.

---

## How to prevent fraudulent returns on Shiprocket?

To prevent fraud:
1. Enable mandatory photo-based QC for all returns
2. Require serial number/barcode verification during QC
3. Set up clear return eligibility rules
4. Monitor return rate per buyer
5. Use Shiprocket Secure for coverage against losses

---

## What is the auto-approval feature for returns?

Auto-approval automatically processes return requests that meet your configured criteria (valid reason, within return window, eligible product) without manual review. Configure in Settings >> Returns >> Auto Approval.

---

## How to configure return notification to buyers?

Buyer notifications for returns can be configured in:
1. Settings >> Communication Settings
2. Enable return-related events (return approved, pickup scheduled, refund processed)
3. Choose communication channels (SMS, Email, WhatsApp)
4. Save settings

---

## What is the SLA for refund processing after return QC?

Refund SLA after QC completion:
* Store credit/wallet: Immediate
* UPI/bank transfer: 3-5 business days
* Credit card: 5-7 business days

Actual timelines depend on payment gateway processing.

---

## How does Shiprocket handle returns for marketplace orders?

For marketplace orders (Amazon, Flipkart), returns typically flow through the marketplace's own return process. Shiprocket handles the reverse logistics (pickup from buyer). Check your channel settings for marketplace-specific return configurations.

---

## Can I use different couriers for forward and return shipments?

Yes. The courier for return pickup doesn't need to be the same as the original forward shipment courier. Shiprocket assigns the best available courier for reverse logistics based on serviceability.

---

## How to handle items returned without original packaging?

For returns without original packaging:
1. During QC, note the missing packaging
2. Update the QC status accordingly
3. Based on your return policy, you may deduct repackaging costs or mark as partial defect
4. Document with photos for any dispute resolution

---

## What is grading in return QC on Shiprocket?

Grading categorizes returned items by quality:
* Grade A: Like new / sellable as new
* Grade B: Minor issues / sellable as refurbished
* Grade C: Major issues / not resalable

Use grading to determine appropriate disposition for returned inventory.

---

## How to handle returns where buyer misused the product?

For returns showing clear misuse:
1. Mark QC as 'Customer Damaged/Misused'
2. Document with photos
3. Based on your return policy, decline the return or deduct usage charges
4. Communicate with the buyer citing QC findings

---

## Does Shiprocket support returns for international shipments?

Shiprocket primarily handles domestic returns within India. For international return requirements, contact Shiprocket's international team (SRX) for guidance on cross-border reverse logistics.

---

## What is the maximum return window I can set on Shiprocket?

Shiprocket allows sellers to configure their return window based on their business policy. You can set the return window (days from delivery) in Settings >> Returns. The maximum configurable window depends on your account settings.

---

## How to track the return shipment?

To track a return shipment:
1. Go to Returns section
2. Find the specific return order
3. Click on the return order
4. View the tracking status and AWB details
5. Track on the courier's website using the reverse AWB number

---

## Can a seller initiate a return on behalf of the buyer?

Yes. Sellers can create return orders from the Returns section in the Shiprocket panel on behalf of the buyer. This is useful when buyers contact you directly for returns outside the Post-Ship page flow.

---

## What is the return rate benchmark for e-commerce in India?

Return rates vary significantly by category:
* Fashion/Apparel: 20-40%
* Electronics: 5-10%
* Beauty/Personal Care: 3-8%
* Books/Media: 2-5%

Monitor your return rate against category benchmarks and investigate causes for rates above industry average.

---

## How to add internal notes to a return order on Shiprocket?

Internal notes can be added to return orders from the return order details page. These notes are visible only to your team and help track the return handling process internally.
