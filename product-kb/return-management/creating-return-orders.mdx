## What information is required to create a return order

Required: original order ID or AWB number, return reason, pickup address (buyer's address with pincode), contact number, and product details. Optionally enable QC and specify the refund mode.

---

## Can I create return orders in bulk

Yes. Bulk return order creation is available via CSV upload. Go to Returns >> Bulk Create Return and download the sample template. Fill in the required fields and upload.
