## How do I enable 'Returns' on my Post Ship tracking page?

Shiprocket sellers can now accept returns for their products directly from their Post Ship page. To enable this:
1. Go to Settings >> Post Ship Tracking
2. Find the Returns option
3. Enable returns on your tracking page
4. Configure the return window and eligible reasons
5. Save settings

Buyers can now initiate returns directly from their order tracking page.
