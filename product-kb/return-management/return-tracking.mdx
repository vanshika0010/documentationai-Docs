## How do I enable 'Returns' on my Post Ship tracking page?

Shiprocket sellers can now accept returns for their products directly from their Post Ship page. To enable this:
1. Go to Settings >> Post Ship
2. Find the Returns section
3. Enable the 'Allow Returns' toggle
4. Configure return window (number of days from delivery)
5. Set eligible return reasons
6. Save settings

Buyers can now see a 'Return Order' button on their tracking page and initiate returns directly.
