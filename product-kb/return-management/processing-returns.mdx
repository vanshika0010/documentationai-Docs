## How to process a return order on Shiprocket?

To process a return:
1. Go to Returns from the left menu
2. Find the return order
3. Review the return request details
4. Approve or reject the return
5. If approved, the return pickup is initiated
6. Once the item is received back, complete QC
7. Process refund/replacement based on QC outcome

---

## What are the refund modes available for returns on Shiprocket?

Refund modes available:
1. Original payment source (credit card, UPI, etc.)
2. Store credit/wallet
3. Bank transfer
4. Replacement (exchange for the same or different item)

---

## How long does return processing take on Shiprocket?

Return processing timeline:
1. Return pickup: 2-5 business days after approval
2. Transit back to seller: 3-7 business days depending on distance
3. QC processing: 1-2 business days
4. Refund initiation: 1-3 business days after QC

Total end-to-end: 7-17 business days typically.
