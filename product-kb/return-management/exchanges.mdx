## How do I ship an exchange order?

* After creating an exchange order in the Returns Panel, go to the [Orders](https://app.shiprocket.in/seller/orders/new) page.
* The exchange (replacement) order will appear as a new order.
* Process it like a regular forward shipment - assign courier, generate label, request pickup.

---

## How to create an exchange order on Shiprocket?

To create an exchange:
1. Go to Returns section
2. Click 'Add Return Order'
3. Fill in all required details
4. Under Delivery section, toggle ON 'Exchange Order'
5. Fill in details for the replacement item (product, size, color, etc.)
6. Review and confirm

The return pickup and replacement shipment are coordinated automatically.

---

## Does Shiprocket support instant exchange?

Shiprocket supports exchange orders where the replacement can be shipped either:
1. Simultaneously with return pickup (instant exchange)
2. After receiving and QC-ing the returned item (standard exchange)

Configure your preference in Settings >> Returns.

---

## What is the difference between exchange and return on Shiprocket?

Return: Item comes back → refund issued to buyer.

Exchange: Item comes back → replacement item sent to buyer. No monetary refund.

---

## How are exchange shipping charges handled?

For exchanges:
* Return pickup: Reverse logistics charges apply
* Replacement shipment: Standard forward shipping charges apply

You can configure whether buyer bears exchange shipping charges or if it's complimentary, in your return policy settings.

---

## What happens if the exchange item is out of stock?

If the requested exchange item is out of stock:
1. Notify the buyer
2. Offer alternatives (different variant, full refund, store credit)
3. Process accordingly based on buyer's choice
4. Update the exchange order accordingly

---

## How to track an exchange order on Shiprocket?

An exchange involves two shipments:
1. Return leg: Track via the return AWB number in the Returns section
2. Replacement leg: Track via the new order AWB in the Orders section

Both are visible in their respective sections of the Shiprocket panel.
