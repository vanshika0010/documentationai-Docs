<AccordionGroup>
  <Accordion title="How do exchanges work in Shiprocket?">

For an exchange, Shiprocket can coordinate a simultaneous reverse pickup (collecting the original item from the buyer) and forward shipment (delivering the replacement). This ensures a smooth exchange experience.

  </Accordion>
</AccordionGroup>

<AccordionGroup>
  <Accordion title="How to create an exchange order in Shiprocket?">

Go to Returns >> Create Return. Select 'Exchange' as the return type. Enter the original order details and the replacement product details. The system will create both a return and a new forward shipment.

  </Accordion>
</AccordionGroup>
