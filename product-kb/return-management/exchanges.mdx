## How to process an exchange order on Shiprocket?

To process an exchange:
1. Go to Returns from the left menu
2. Find the return request for exchange
3. Approve the return/exchange request
4. The reverse pickup is initiated (return of original item)
5. Simultaneously or after receiving return, create a new forward shipment for the replacement item
6. Process the replacement order through normal shipping workflow

---

## What is the difference between return and exchange on Shiprocket?

Return: Item comes back to seller + refund goes to buyer.

Exchange: Item comes back to seller + new item is sent to buyer. No monetary refund, but a replacement shipment is created.

---

## Can I offer size/color exchanges on Shiprocket?

Yes. Exchange orders allow buyers to request a different variant (size, color) of the same product. Configure exchange options in Settings >> Returns & Exchanges.

---

## How does Shiprocket handle exchange shipping charges?

For exchanges:
* Return pickup: Reverse logistics charges apply
* Forward replacement shipment: Standard shipping charges apply

Sellers can configure whether the buyer bears exchange shipping charges or if it's free exchange.

---

## What happens if the exchange item is out of stock?

If the requested exchange item is out of stock:
1. Notify the buyer
2. Offer an alternative (different variant, refund, or store credit)
3. Process accordingly based on buyer's preference

---

## How to track an exchange order on Shiprocket?

An exchange has two tracking components:
1. Return shipment (reverse pickup): Track via the return order AWB
2. Replacement shipment (forward): Track via the new order AWB

Both are visible in the Returns and Orders sections respectively.

---

## Can I offer instant exchange on Shiprocket?

Instant exchange (shipping replacement before receiving return) is a configuration option. Contact Shiprocket support to check if instant exchange is supported for your account and how to configure it.
