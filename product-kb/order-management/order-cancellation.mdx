## How can I delete an order?

You cannot delete an order from the shiprocket account. You can cancel the order if it has not been shipped yet.

---

## How to cancel an order on Shiprocket?

To cancel an order:
1. Go to Orders from the left menu
2. Find the order you want to cancel
3. Click on the three dots menu (...) or Order Actions
4. Select 'Cancel Order'
5. Choose the cancellation reason
6. Confirm cancellation

Note: Orders can only be cancelled if they haven't been picked up by the courier yet.

---

## Can I cancel an order after it has been shipped on Shiprocket?

Once an order has been picked up and is in transit, it cannot be directly cancelled. You would need to:
1. Wait for delivery or RTO
2. If the buyer refuses delivery, it will automatically become an RTO
3. You can also attempt to recall the shipment by contacting support, but this is not always possible

---

## What happens after I cancel an order on Shiprocket?

After cancellation:
1. The shipping charges are refunded to your Shiprocket wallet (if already deducted)
2. The order status changes to 'Cancelled'
3. The AWB is released
4. The order cannot be re-activated once cancelled

---

## Can I cancel a COD order on Shiprocket?

Yes. COD orders can be cancelled using the same cancellation process as prepaid orders, as long as the order hasn't been picked up.

---

## How to cancel multiple orders at once on Shiprocket?

For bulk order cancellation:
1. Go to Orders
2. Select multiple orders using checkboxes
3. Click 'Bulk Cancel' from the actions menu
4. Select cancellation reason
5. Confirm

---

## What is the time limit to cancel an order on Shiprocket?

Orders can be cancelled anytime before the courier picks them up. Once picked up (status: Picked/Shipped), cancellation is not possible and you would need to wait for RTO.
