<AccordionGroup>
  <Accordion title="Does Shiprocket Checkout support all payment modes?">

Yes, Shiprocket Checkout supports all payment modes: UPI, Credit/Debit Cards, Netbanking, Wallets, BNPL, and EMI options.

  </Accordion>
</AccordionGroup>

<AccordionGroup>
  <Accordion title="Does Shiprocket Checkout have a payment gateway switch option for downtime?">

Yes, Shiprocket Checkout provides a payment gateway switch option. If one payment gateway is facing downtime, it automatically switches to a secondary gateway so the customer can complete checkout hassle-free.

  </Accordion>
</AccordionGroup>

<AccordionGroup>
  <Accordion title="Does Shiprocket Checkout support Paytm payment gateway?">

No, Shiprocket Checkout doesn't support Paytm payment gateway.

  </Accordion>
</AccordionGroup>

<AccordionGroup>
  <Accordion title="How to create a discount on checkout?">

Go to Settings >> Discounts >> Create. Choose from: Amount of Products, Amount off Cart, Tiered Discount, Buy X Get Y, Bundle, Upselling, or Bank Offers. Select Automatic or Coupon Code method, fill in the configuration, criteria, and validity details. Once created, you can enable/disable from the All Discounts section.

  </Accordion>
</AccordionGroup>
