## How do I configure Bundle discounts on Shiprocket Checkout?

Bundle discounts can be easily created in the shiprocket checkout dashboard.
1. Bundle discount can be created in 2 ways: X products for Rs. Y or X Discount for Y products
2. Bundle discount can be both automatic (Auto Applied) and Coupon based.
3. Bundle discount can be created on individual products or a collection of products by selling X products at Rs Y.

With shiprocket checkout, you can create Urchin Tracking Module (UTM) based discounts. ## How to add prepaid discount on my orders from checkout?

To add a prepaid discount value on Shiprocket Checkout,
* Go to Settings > Shipping Settings from the left menu.
* Write a fixed or percentage discount you want to apply to your order.
* You can choose to apply the maximum of fixed or percentage discount on the order.

---

## How to add extra charges on my COD orders on checkout?

To add extra charges on your COD orders from Shiprocket Checkout, follow these steps:
* Go to Settings > Shipping Settings from the left menu.
* Write a fixed or percentage discount under COD charges.
* You can choose to apply the maximum of fixed or percentage discount on the order.

## how to add discount without coupon code on shiprocket checkout?

Automatic discounts help in applying discounts without applying coupon code manually on the checkout. You can configure an automatic discount on the checkout dashboard by using the below steps:

1. Go to Settings from the left menu.
2. Select Discounts.
3. Click on Create and choose your discount type.
4. Select the "Automatic" discount method from different options and enter the discount name.
5. Configure Details: Fill in the necessary details for configuration, criteria, functionality, and validity of the discount.
6. Save and Enable: Once created, your discount will appear in the All Discounts section where you can enable or disable it as needed.

## I'm not able to import discounts from shopify on Checkout?

Shiprocket checkout only supports import of "Coupon code" discounts on checkout dashboard and automatic discounts can't be imported for shopify store. In case, you are facing issue in importing code based discounts, then below are the possible reasons:
1. Access is missing for shiprocket checkout for the particular coupon code in "Sales channel access" section on shopify.
2. If coupon code being imported is "Amount of product", it is possible that the permission is missing to access the particular product for checkout.
3. Could be a catalogue sync issue which can be done manually by checkout team.

In the issue still persists, reach out to Checkout support team.
