## Does Shiprocket Checkout allows customisation on the UI as per the colour scheme of the website?

Yes, Shiprocket Checkout allows customisation on the UI as per the colour scheme of the website using our theme customization feature. You can customize the color, logo and other aspects of the checkout.

---

## How does Shiprocket Checkout help in communicating correctly to consumers by using the right language?

Shiprocket checkout help in communicating to the consumers in the right language as it identifies the device language of the consumer and auto-translates the checkout in their language. This helps in communicating in the consumer's native language and helps in increasing conversions.

---

## Can my user interface (UI) on my website's checkout page be changed post the integration of Shiprocket checkout?

Yes, post the integration of Shiprocket checkout, the user interface (UI) on checkout page can be changed by the checkout integration team. Please raise a request to the checkout team at checkoutsupport@shiprocket.com for the UI change request.

---

## Can I use my own Trust Badges on Checkout?

Yes, you can use your own trust badges on Checkout. Contact the checkout team at checkoutsupport@shiprocket.com to configure your custom trust badges.

---

## Can I add my own logo to the Checkout page?

Yes, you can add your own logo to checkout page and to configure your logo on the checkout, contact the checkout team at checkoutsupport@shiprocket.com.

---

## What's the process to edit the checkout UI using Shiprocket's checkout theme customization feature?

To edit the checkout UI using Shiprocket's checkout theme customization feature, follow these steps on your Checkout dashboard:
* Open the Checkout Dashboard and click on "Branding" from the left menu.
* You can customize the following UI elements: Primary Colour, Secondary Colour, Banner/Logo, OTP Page Banner.
* Once done, click on "Update" to save the changes.
