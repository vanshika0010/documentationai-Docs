<AccordionGroup>
  <Accordion title="How to configure custom shipping rules on Checkout?">

Go to Settings >> Shipping Settings >> Custom Rules >> Create Rule. You can create rules for shipping visibility, prepaid discount, COD charges, and COD to prepaid based on parameters like invoice value, destination pincodes, product SKU, and UTM parameters.

  </Accordion>
</AccordionGroup>

<AccordionGroup>
  <Accordion title="How to set free shipping on Checkout?">

You can set free shipping by setting the shipping charges to 0 for all delivery methods (Rush, Express, Standard) in Settings > Shipping Settings.

  </Accordion>
</AccordionGroup>
