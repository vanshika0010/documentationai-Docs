<AccordionGroup>
  <Accordion title="How can I get an API key for Checkout?">

For Shopify: Login to Shopify dashboard >> Settings >> Apps & Sales channel >> Develop apps >> Select Fastrr checkout >> API Credentials.

For WooCommerce: Login to WooCommerce dashboard >> WooCommerce >> Settings >> Advanced >> Rest API >> Add Key. Set Description as 'Fastrr' and Permissions as 'Read/Write,' then click Generate API key.
