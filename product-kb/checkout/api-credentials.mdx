## How can I get an API key for Checkout

**Shopify:** Login to Shopify Dashboard >> Settings >> Apps & Sales Channels >> Develop apps >> Select Fastrr checkout >> API Credentials. Copy the Admin API access token, Storefront API access token, API key, and secret key.

**WooCommerce:** Login to WooCommerce Dashboard >> WooCommerce >> Settings >> Advanced >> REST API >> Add Key. Set Description to 'Fastrr,' Permissions to 'Read/Write,' then click 'Generate API Key.' Share the Consumer Key and Consumer Secret with the checkout integration team.
