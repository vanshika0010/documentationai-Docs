## Does shiprocket checkout provide integration with different CRM platforms?

Yes, shiprocket checkout can be integrated with different CRM platform via webhooks and multiple webhooks can be subscribed at the same time from the shiprocket dashboard. Follow the below steps to integrate webhook with checkout:
* Shiprocket dashboard >> Checkout Dashboard >> Settings >> Webhooks >> Add webhook
* Multiple fields need to be configured while setting up the webhook which are listed below:
* Service Provider: The external service or application that sends or receives the webhook.
* Webhook Type: The category or event type that the webhook is tracking (e.g., Real Time, Abandon Cart).
* Time (seconds): When the webhook will be triggered which is available with the "Abandoned Cart" webhook type only.
* Actions: Available operations you can perform, such as edit and toggling the webhook on and off.

## How can I increase my AoV using Shiprocket Checkout?

Shiprocket checkout helps in increasing AOV by using below features:-
1. Aftersell : This feature helps in offering various products at the Thank you page once an order is placed by the customer and after customer clicks on it, it directly gets re-directed to the checkout.
2. Prepaid Discount (Based on Invoice Value) : Tiered prepaid discounts can be offered based on invoice value slab which helps in offering higher prepaid discount on higher invoice value.
3. Tiered Discounts : Tiered discounts can be configured on the checkout based on cart value and quantity. Higher the cart value or quantity, higher the discount.
4. Discounts ( Based on payment methods) : Different discounts can be made for different payment methods like UPI, Cards, etc which helps in offering more discount on payment method which is least expensive for you based on MDR commissions of the payment gateways.
5. Shipping Charges: Shipping charges can be charged for the shipments where logistics cost is higher so that the logistics cost can be recovered and it also helps in increasing the average order value.
6. Paylater Options: Simpl Paylater & Simpl Pay-In-3 payment options can be integrated which provide EMI options on the checkout which helps in increasing the AOV on the checkout.

## How to send Shiprocket Checkout data to Moengage for tracking?

To share Shiprocket Checkout data, follow these steps:
* Go to Settings > Tracking Info from the left menu.
* This section has four options namely, Base URL, App ID, Data API ID and Data API Key
* The Base URL is common for every seller - https://api-03.moengage.com/v1/, the other three fields can be easily copy-pasted from the Moengage dashboard by clicking on settings and then navigating to the API section.

Customer Mapping on MoEngage: To ensure proper customer mapping on MoEngage, you have the option to use either the Email ID or Phone Number of the customer. Please inform us of your preferred method. This will allow us to make the necessary adjustments in the backend configuration, ensuring that event mapping is accurately reflected on the MoEngage dashboard.

All these fields are mandatory to fill in order to share the event data with Moengage.

Currently, we share three events as per the default Moengage integration:
* Phone Number Added - Shared once the customer has entered his mobile number and requested OTP.
* Payment Initiated - Shared at the time of prepaid payment initiation only.
* Order Placed - Shared once an order is created, Prepaid or COD.

Note: Moengage is totally different product from Shiprocket Engage product and has nothing to do with Shiprocket Engage

## how can I get an API key for Checkout?

Shopify Platform:
* Login to Shopify dashboard >>Settings >>Apps & Sales channel >> Develop apps >> Select Fastrr checkout (From list of apps) >> API Credentails
* Please select the below details from this section: Admin API access token, Storefront API access token, API key, and secret key

Woo-commerce Platform:
* Login to woo-commerce dashboard >> Woocommerce Tab (On navigation bar) >> Settings >> Advanced >> Rest API >> Add Key
* In Key details, please enter the following information:
** Description : Fastrr
** Permissions : Read/Write
* Click on Generate API key and "Consumer Key" & "Consumer Secret" will be generated.
* Share this information with the checkout integration team for further integration.

## my shopify orders are not syncing on Checkout panel what could be the reason?

If your Shopify orders are not syncing, here are some steps you should check:

1. Order Sync Status: Ensure that the Order Sync is turned on for your integrated channel. The 'Status to fetch' field under the 'Pull Order Statuses' section should match the status in Shopify.
2. Integration Settings: Double-check the integration settings between Shopify and Shiprocket to ensure everything is configured correctly.
3. Manual Sync: If automatic syncing is not working, you can manually trigger the order synchronization process by clicking on the 'Sync Order' button located at the top right corner of the Orders page in your Shiprocket account.
4. Network Issues: Sometimes, network connectivity problems can cause delays in syncing.

If the issue persists after checking these points, consider creating a support ticket for further assistance.
