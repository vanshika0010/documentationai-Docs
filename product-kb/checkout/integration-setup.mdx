## How much time will it take for Shiprocket Checkout to be integrated in my store?

## Does shiprocket checkout provide integration with different CRM platforms?

Yes, shiprocket checkout can be integrated with different CRM platform via webhooks and multiple webhooks can be subscribed at the same time from the shiprocket dashboard. Follow the below steps to integrate webhook with checkout:
* Shiprocket dashboard >> Checkout Dashboard >> Settings >> Webhooks >> Add webhook
* Multiple fields need to be configured while setting up the webhook which are listed below:
* Service Provider: The external service or application that sends or receives the webhook.
* Webhook Type: The category or event type that the webhook is tracking (e.g., Real Time, Abandon Cart).
* Time (seconds): When the webhook will be triggered which is available with the “Abandoned Cart” webhook type only.
* Actions: Available operations you can perform, such as edit and toggling the webhook on and off.

## How can I increase my AoV using Shiprocket Checkout?

Shiprocket checkout helps in increasing AOV by using below features:
1. Aftersell: This feature helps in offering various products at the Thank you page once an order is placed by the customer and after customer clicks on it, it directly gets re-directed to the checkout.
2. Prepaid Discount (Based on Invoice Value): Tiered prepaid discounts can be offered based on invoice value slab which helps in offering higher prepaid discount on higher invoice value.
3. Tiered Discounts: Tiered discounts can be configured on the checkout based on cart value and quantity. Higher the cart value or quantity, higher the discount.
4. Discounts (Based on payment methods): Different discounts can be made for different payment methods like UPI, Cards, etc which helps in offering more discount on payment method which is least expensive for you based on MDR commissions of the payment gateways.
5. Shipping Charges: Shipping charges can be charged for the shipments where logistics cost is higher so that the logistics cost can be recovered and it also helps in increasing the average order value.
6. Paylater Options: Simpl Paylater & Simpl Pay-In-3 payment options can be integrated which provide EMI options on the checkout which helps in increasing the AOV on the checkout.

## How to add a payment gateway on Shiprocket Checkout?

To add or activate a payment gateway on Shiprocket Checkout, follow these steps:
* Go to Settings > Payment from the left menu.
* Click on the Add new gateway button and choose from the available gateway options.
* Each and every payment gateway has a specific SOP to integrate with fastrr and requires different credentials.
* Choose the one you want and complete the remaining steps to successfully integrate.

---

## How to setup primary and secondary payment gateway on Shiprocket Checkout?

For each payment mode, you can select the primary and secondary payment gateway on Shiprocket Checkout by choosing from the payment gateways that you have integrated. This is mainly used for UPI, where in case the Primary PG UPI is down, we can redirect the request to the secondary PG UPI for processing payment. Navigate to Settings > Payment from left menu to set this up.

## my shopify orders are not syncing on Checkout panel what could be the reason?

If your Shopify orders are not syncing, here are some steps you should check:

1. Order Sync Status: Ensure that the Order Sync is turned on for your integrated channel.
2. Integration Settings: Double-check the integration settings between Shopify and Shiprocket.
3. Manual Sync: If automatic syncing is not working, you can manually trigger the order synchronization process by clicking on the ‘Sync Order’ button.
4. Network Issues: Sometimes, network connectivity problems can cause delays in syncing.

If the issue persists after checking these points, consider creating a support ticket for further assistance.
