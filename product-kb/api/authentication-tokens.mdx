## I'm getting "unauthorized, you do not have the required permissions" via API

This error usually arises because the token you are using belongs to a different account. There are two sets of credentials for your Shiprocket account: login credentials and API credentials. If you generate the token using login credentials, you will encounter this error. Please use the API credentials to generate the token.

---

## What is the validity of the API token

The validity of the API token is 10 days.

---

## I'm getting "Wrong number of segments" in API

This error occurs when an incorrect token or no token has been passed in the authorization header. Ensure that you are correctly generating and including the token in your API requests.

---

## I'm getting "invalid token" when running API calls

The token is invalid — you need to regenerate the token with correct credentials. If the token is wrong, the system throws an "invalid token" error.

## How can I integrate Shiprocket with my Odoo website

1. Visit the Shiprocket website and sign up for an account if you haven't already.
2. Access the API documentation provided by Shiprocket at https://apidocs.shiprocket.in for integration details.
3. Use the API keys provided in your Shiprocket account to authenticate your requests.
4. Implement the necessary API calls in your website's backend to manage orders, shipments, and tracking.
5. Test the integration thoroughly to ensure everything is working as expected.

## How to setup a webhook with Shiprocket to get tracking updates

You can set up a webhook with Shiprocket to get tracking updates proactively whenever there is a new tracking event.

**Setup:**
* Go to Settings > API > Webhooks from the left menu
* Add the webhook URL and enable the toggle
* Add the security token (optional)

**Webhook Specifications:**
* Method: POST
* Content-Type header should be set to application/json
* Do not use keywords like shiprocket, kartrocket, sr, or kr in your webhook URL
* Security token should be an x-api-key
* The URL should return only code 200 in response

For more details, visit https://apidocs.shiprocket.in/#webhooks
