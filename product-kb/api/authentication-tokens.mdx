<AccordionGroup>
  <Accordion title="I'm getting 'unauthorized, you do not have the required permissions via running API.">

This type of error usually arises because the token you are using belongs to a different account. There are two sets of credentials for your Shiprocket account: login credentials and API credentials. If you generate the token using login credentials, you will encounter this error. Please use the API credentials to generate the token.

  </Accordion>
</AccordionGroup>

<AccordionGroup>
  <Accordion title="what is the validity of the api token?">

The validity of the API token is 10 days.

  </Accordion>
</AccordionGroup>

<AccordionGroup>
  <Accordion title="I'm getting 'Wrong number of segments' in api">

This error occurs when an incorrect token or no token has been passed in the authorization header. Ensure that you are correctly generating and including the token in your API requests.

  </Accordion>
</AccordionGroup>

<AccordionGroup>
  <Accordion title="I'm getting 'invalid token' when I'm running API calls.">

The token is invalid you need to regenerate the token with correct credentials and use the same. If the token is wrong system throws an error as an invalid token.

  </Accordion>
</AccordionGroup>

<AccordionGroup>
  <Accordion title="How to setup webhook with shiprocket to get tracking updates?">

You can set up a webhook with Shiprocket to get tracking updates. We will proactively notify your system whenever there is a new tracking event for an order.

Setup:
* Go to Settings > API > Webhooks from the left menu
* Add the webhook URL
* Enable the toggle
* Add the security token (not mandatory)
* When we get a new tracking event, a POST request is made to the callback URL you added to your Shiprocket account.

Webhook Specifications:

* Method: POST
* The Content-Type header should be set to application/json
* Please refrain from using keywords like shiprocket, kartrocket, sr, or kr in your webhook URL
* Security token should be anx-api-key
* The URL should be set to send only code 200 in response.
For more details, visit this link: https://apidocs.shiprocket.in/#webhooks

  </Accordion>
</AccordionGroup>

<AccordionGroup>
  <Accordion title="How integrate Webhook into my Shiprocket account?">

To integrate the Webhook into the shiprocket account, follow these steps:
1. Go to 'Settings' from the left menu.
2. Under the settings page click on 'API' >> 'Webhooks'.
3. Then, you will navigate to the Shipment Webhook Settings page.
4. ON toggle button to Enable the Webhook.
5. Once you enable the Webhook you need to enter the URL and Token (optional).
6. Then, click on the 'Test Webhook' button to test.
7. Finally, click on 'Save Webhook' button.

  </Accordion>
