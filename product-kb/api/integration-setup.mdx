  <Accordion title="How to create an API user? Can I have more than one API user?">

Yes, you can add up to 25 API users. To integrate your website with Shiprocket, you can follow these general steps:

* From the left-hand menu, go to Settings → API → Add New API User
* Click on "Create API User."
* In the pop-up form:
** Enter a unique email address (must be different from the one used for your main Shiprocket login).
** Under Modules to Access, select the relevant API modules you want your user to access.
** Under Buyer's Details Access, choose either "Allowed" or "Not Allowed" based on your requirement.
** Click on "Create User."
* The password for the API user will be sent to your registered email address (not the API user email ID).

If you need more specific guidance or have any questions about the integration process, feel free to ask!

  <Accordion title="Facing issue with API integration. Help me!">

* We apologize for the inconvenience you're experiencing with the API integration. We suggest you to please raise a ticket to our support team and provide more details about the specific problem you are facing.
* To raise your concern with our support team, simply follow these steps:
   * Navigate to the "Help & Support" section from the left menu.
   * Click on the "Create Ticket" button located at the top-right corner of the page.
   * In the "Category" dropdown menu, select "Technical Support."
   * From the "Subcategory" dropdown menu, choose "Issues with Channel & API Integration."
   * Select whether the issue is related to "Channel Integration" or "API Integration."
   * Enter all the mandatory details regarding your issue.
   * Finally, click on the "Create Ticket" button to submit your request to our support team.
* Our team will review your ticket and assist you with resolving the integration issues as quickly as possible.

  </Accordion>
