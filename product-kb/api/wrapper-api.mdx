## What is a wrapper API

A wrapper API is an API that encapsulates or "wraps around" another API, providing an additional layer of abstraction or functionality. It acts as an intermediary between the client and the original API, allowing for modifications, enhancements, or simplifications to the original API's functionality. Wrapper APIs are often used to improve performance, security, or usability, or to provide a more consistent interface across multiple APIs.
