## What are Buyer Communication Settings?

Buyer Communication Settings in Shiprocket allow you to configure how and when notifications are sent to your buyers about their orders. You can customize:
1. Communication channels (SMS, Email, WhatsApp)
2. Order statuses for which notifications are sent
3. Brand name shown in communications
4. Custom message content

Access from Settings >> Communication Settings in your Shiprocket panel.

---

## How to customize buyer notifications on Shiprocket?

To customize buyer notifications:
1. Go to Settings >> Communication Settings
2. Select the channel (SMS/Email/WhatsApp)
3. Choose the order statuses for which you want to send notifications
4. Customize the message template
5. Set your Communication Brand Name
6. Save settings

---

## What is Communication Brand Name in Shiprocket?

Communication Brand Name is the name displayed to buyers in order update messages. By default, it shows "Shiprocket". You can change it to your brand name so buyers recognize your communications.

Update from Settings >> Communication Settings >> Communication Brand Name.

---

## How to enable WhatsApp notifications for buyers on Shiprocket?

To enable WhatsApp notifications:
1. Go to Value Added Services >> Notify in the left menu
2. Click Activate Now for WhatsApp Communication
3. Select the order statuses you want to notify buyers about
4. Save settings

WhatsApp notifications are part of the Engage/Notify feature.

---

## Can I send SMS notifications to buyers on Shiprocket?

Yes. Shiprocket sends SMS notifications to buyers for order status updates. You can configure which statuses trigger SMS notifications from Settings >> Communication Settings.
