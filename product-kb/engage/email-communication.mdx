## If the customer confirms the order first and then cancels the order, will this be updated on Engage?

No. The response won't be captured. An automated response will be triggered to the buyer saying that the confirmation request has already been processed.

## Why is my customer list not uploading properly on Engage?

If you're facing issues with uploading customer contacts:
1. Ensure the file is in the correct format (CSV).
2. Check for invalid phone numbers or email addresses in the list.
3. Make sure the file doesn't contain any special characters or formatting issues.
4. Try reducing the file size by splitting it into smaller batches.
5. If the issue persists, contact srengage@shiprocket.com for assistance.
