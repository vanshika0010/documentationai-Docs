## Can I use different languages for messaging using Engage?

Yes, Engage 360 supports multilingual messaging. You can create WhatsApp templates in multiple languages (Hindi, Tamil, Bengali, etc.) and submit them for Meta approval. The language version used can be set per campaign or journey based on customer preference.
