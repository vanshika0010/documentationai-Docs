<AccordionGroup>
  <Accordion title="What is the chatbot feature in Engage?">

Engage's chatbot allows you to create automated conversation flows on WhatsApp that respond to customer inquiries without manual intervention. Set up keyword triggers, interactive menus, and multi-step flows for order tracking, FAQs, and support.

  </Accordion>
</AccordionGroup>

<AccordionGroup>
  <Accordion title="How to create a chatflow in Engage?">

Go to Engage >> Chatbot >> Create Chatflow. Define the trigger (keyword or entry point), design the conversation flow using the visual builder, add response nodes, and activate the flow. Test before going live.

  </Accordion>
</AccordionGroup>
