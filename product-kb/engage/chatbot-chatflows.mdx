## How to Create a Custom Chatflow in Engage?

These are the steps that you can follow to create custom chatbot:
1. Click on Custom Chatbot Builder from the side panel.
2. Click on Create Flow
3. Enter name of flow
4. Select trigger for the flow
5. Create your flow using the node options available
6. Save and activate the flow

---

## How can I manage, view, activate, or deactivate my chatflow in Engage?

Once your template is saved, you can manage your chat flows by accessing the My Chatflows home page, where you can view, activate, or de-activate all the created chatflows.

---

## How to check if my chatflow template is active or not on Engage?

When you have created the chat flow, you can click on it to find if your templates have been "Rejected" or "Active"
* If Rejected - This template is not active and will not trigger for any user.
* If Active - This template is active and will trigger for users based on the configured conditions.

## How can I edit or modify my chatflow template on Engage?

1. To modify a template, just click on the chat flow and you'll be re-directed to the Chat flow edit page.
2. You can click on the template you want to modify, make your changes, and save.
3. Note: Some modifications may require re-approval.

## What are the key components of a chatflow in the Custom Chatbot Builder on Engage?

A chatflow is made up of nodes or blocks, each representing a message, user input, action, or logic. Core components include:
1. Message blocks (text, image, video, document, audio)
2. Input/Response blocks (for capturing user replies)
3. Condition blocks (branching logic based on user input)
4. Delay blocks (for timed follow-ups)
5. Action blocks (API calls, tagging, segment updates)
6. Handoff blocks (transfer to human agent)

## Can I use the chatflow to collect multiple inputs over multiple steps on Engage?

Absolutely. You can build a multi-step form-style flow that collects fields one by one (like name, email, address, preferred product, etc.), validates responses, and stores the data for follow-up use.

## Can I create multilingual chatbot flows on Engage?

Yes. You can duplicate flows in Hindi and English, or dynamically set the language based on user input or location, e.g.:
1. "Choose your language: English / Hindi"
2. Based on the response, route to the appropriate language flow

## How do I manage chatbot changes without affecting live users on Engage?

You can:
1. Create and edit a draft version of the bot
2. Test it internally
3. Publish only after approval
Changes do not affect users already in the flow until they re-enter.

## What are the use cases or uses for custom chatbot on Engage?

Engage 360's Custom Chatbot automates order-related communication seamlessly. For COD orders, the bot confirms the order by asking users to verify before shipping, reducing fraudulent orders. It also handles address verification by prompting users to confirm or update their delivery address, minimizing failed deliveries. Post-shipment, the bot facilitates COD-to-Prepaid conversion by sending personalized payment links to encourage prepaid transactions.

## How do I set up automated chat replies?

Once connected, click Create Flow to build your chatbot.

## How can I test or edit my existing chat flows?

After creating a chat flow, you'll see options to Enable/Disable, Export data, or Modify flow on the chat flow screen. You can use these controls to test the flow with your own number, make edits, and re-activate when ready.
