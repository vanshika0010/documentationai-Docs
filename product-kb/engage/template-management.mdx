<AccordionGroup>
  <Accordion title="How to create a WhatsApp message template in Engage?">

Go to Engage >> Templates >> Create Template. Select the template category (Marketing, Utility, or Authentication), write your message, add variables for personalization (e.g., {{customer_name}}, {{order_id}}), and submit for Meta approval. Approval typically takes 24-48 hours.

  </Accordion>
</AccordionGroup>

<AccordionGroup>
  <Accordion title="Why was my WhatsApp template rejected?">

Common reasons for template rejection: content violates Meta's policies, missing or incorrect variable format, template resembles spam, or the category is incorrect. Review Meta's template guidelines and resubmit.

  </Accordion>
</AccordionGroup>
