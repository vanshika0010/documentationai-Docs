## What is Shiprocket Radar?

Shiprocket Radar is an AI-powered courier intelligence tool that provides real-time insights on courier performance across pincodes. It helps sellers make smarter courier selection decisions based on actual delivery performance data, stress indicators, and predictive analytics.

---

## What data does Radar provide?

Radar provides:
1. Real-time pincode-level delivery performance data
2. Courier stress indicators (high NDR/RTO areas)
3. Delivery success rate by courier and pincode
4. Recommended courier for each delivery route
5. Historical performance trends
