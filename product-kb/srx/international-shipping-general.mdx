<AccordionGroup>
  <Accordion title="What is ShiprocketX (SRX)?">

ShiprocketX (SRX) is Shiprocket's international shipping solution. It enables Indian sellers to ship to 220+ countries using a network of global courier partners, with end-to-end tracking, customs documentation support, and competitive rates.

  </Accordion>
</AccordionGroup>

<AccordionGroup>
  <Accordion title="How to create an international shipment on Shiprocket?">

Go to Orders >> Create Order and select international as the shipment type. Enter buyer details (with country), product details including HS code and declared value, then select a courier from the available international options.

  </Accordion>
</AccordionGroup>
