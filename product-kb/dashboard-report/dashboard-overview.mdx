## What information is available on the Shiprocket dashboard

The Shiprocket dashboard provides an overview of your shipments including total orders, pending pickups, in-transit shipments, delivered orders, RTO count, and wallet balance. It also shows performance charts and quick access to key tools like the Rate Calculator and Serviceability Checker.

---

## How to use the Rate Calculator on the dashboard

Go to Dashboard >> Rate Calculator. Enter origin pincode, destination pincode, package weight, and dimensions to see shipping rates across all active couriers. This helps you compare costs before assigning a courier.
