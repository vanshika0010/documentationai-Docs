<AccordionGroup>
  <Accordion title="What information is available on the Shiprocket dashboard?">

The Shiprocket dashboard provides an overview of your shipments including total orders, pending pickups, in-transit shipments, delivered orders, RTO count, and wallet balance. It also shows performance charts and quick access to key tools.

  </Accordion>
</AccordionGroup>

<AccordionGroup>
  <Accordion title="How to use the Rate Calculator on the dashboard?">

Go to Dashboard >> Rate Calculator. Enter origin pincode, destination pincode, package weight, and dimensions to see shipping rates across all active couriers.

  </Accordion>
</AccordionGroup>
