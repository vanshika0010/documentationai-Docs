## What functionalities does Shiprocket Sense offer?

Shiprocket Sense provides several advanced APIs, including:
1. RTO Risk – Predict and prevent COD returns before they happen
2. Address Intelligence – Validate buyer addresses before dispatch
3. Pincode Intelligence – Insights on pincode-level delivery performance
4. Serviceability Check – Real-time courier serviceability per pincode

---

## How does Shiprocket Sense help in reducing RTO?

Shiprocket Sense reduces RTO by:
1. Predicting which orders have high RTO probability before shipping
2. Flagging poor-quality addresses for verification before dispatch
3. Recommending better-performing couriers for specific pincodes
4. Enabling data-driven COD blocking for high-risk buyer segments

---

## Is Shiprocket Sense available as an API?

Yes. Shiprocket Sense is primarily an API-based product. All intelligence features are available as REST APIs that can be integrated into your order management system, checkout page, or any custom application.

---

## What is the RTO Risk API in detail?

The RTO Risk API returns a risk assessment for each order:
1. Risk Score (numerical, typically 0-100)
2. Risk Category (Low/Medium/High)
3. Key risk factors contributing to the score
4. Recommended actions (confirm order, verify address, block COD)

Integrate at checkout or order processing to take preventive action.

---

## What is Address Intelligence in Shiprocket Sense?

Address Intelligence API validates and scores delivery addresses:
1. Returns a quality score for the address
2. Identifies missing or incorrect components
3. Suggests standardized address format
4. Flags incomplete addresses that are likely to cause delivery failures

---

## What is Pincode Intelligence in Shiprocket Sense?

Pincode Intelligence provides analytics on specific pincodes:
1. Delivery success rate
2. RTO rate
3. Average delivery time
4. Best performing courier
5. Historical delivery trends

---

## Can Shiprocket Sense be used without API integration?

For sellers who don't want API integration, Shiprocket Sense analytics are also available through the dashboard. You can view RTO risk insights, pincode performance, and courier recommendations without writing code.

---

## How does Shiprocket Sense calculate RTO risk?

RTO risk is calculated using an AI model trained on millions of Shiprocket shipments considering:
1. Buyer's past delivery/return history
2. Pincode-level historical RTO rates
3. Address quality score
4. Order characteristics (COD vs prepaid, order value, product category)
5. Time of order placement

---

## What is the Serviceability Check API in Sense?

The Serviceability Check API provides real-time information on:
1. Which couriers service a specific pincode
2. Available service types (standard, express, COD)
3. Estimated delivery time for each courier
4. Any serviceability restrictions

Use at checkout to show accurate delivery options to buyers.

## Does Shiprocket Sense work in real-time?

Yes. Shiprocket Sense APIs are designed for real-time use at checkout or order processing. Typical API response time is under 200ms, making it suitable for live use during customer checkout.

## What data does Sense use for predictions?

Sense predictions are based on:
1. Shiprocket's network-wide delivery data (anonymized)
2. Your seller-specific historical order data
3. Geographic and demographic data
4. Carrier performance data

No personally identifiable information (PII) is used for predictions.

## How to use Sense API for COD risk management?

To use Sense for COD risk management:
1. Call RTO Risk API at checkout when buyer selects COD
2. If risk score is High, block COD or show warning
3. If risk is Medium, prompt for order confirmation
4. If risk is Low, allow COD without restrictions

This reduces fraudulent COD orders and improves prepaid conversion.

## What is Sense's seller-specific model vs network model?

Sense uses two types of models:
1. Network Model: Trained on all Shiprocket sellers' anonymized data - available from day one
2. Seller-Specific Model: Trained on your own historical data - accuracy improves as your data grows

Both models work together to provide the best predictions.
