## How can I use Shiprocket Sense ?

You can sign up for Shiprocket Sense platform using your email address and password. Once logged in, you can:
1. Access the Sense dashboard
2. Get API credentials from the 'View Credentials' section
3. Integrate the APIs into your system
4. Monitor performance and insights from the dashboard

---

## What is the pricing for Shiprocket Sense?

Shiprocket Sense uses a credit-based pricing model:
1. Each API call consumes a certain number of credits
2. Credits are purchased in advance
3. Different APIs have different credit consumption rates

For current pricing and credit packages, check the Sense dashboard or contact your Shiprocket account manager.

---

## How do credits work in Shiprocket Sense?

Shiprocket Sense operates on a credit system:
1. Purchase credits in advance
2. Each API call (RTO Risk, Address Quality, etc.) deducts credits
3. Monitor credit usage in the Sense dashboard
4. Recharge when credits run low
5. No credits = API calls fail, ensure sufficient balance

---

## How to check remaining credits in Shiprocket Sense?

To check your remaining Sense credits:
1. Log into the Sense platform/dashboard
2. Your current credit balance is displayed on the dashboard
3. Credit consumption history is also available

---

## How to purchase credits for Shiprocket Sense?

To purchase Sense credits:
1. Go to the Sense dashboard
2. Navigate to Billing/Credits section
3. Select a credit package
4. Complete payment
Credits are added to your account immediately.

## Can I get a free trial for Shiprocket Sense?

Shiprocket may offer trial credits for Sense to new users. Check the Sense dashboard or contact your Shiprocket account manager for current trial/freemium options.

## How many API calls can I make with Shiprocket Sense?

The number of API calls depends on:
1. Credits purchased
2. Credits consumed per API type
3. Your subscription tier

Check the Sense dashboard for your current usage and limits.

---

## Does Shiprocket Sense have a monthly subscription or pay-per-use model?

Shiprocket Sense offers credit-based pricing which is essentially pay-per-use. You purchase credits and consume them as you make API calls. There may also be subscription tiers that include a set number of credits per month. Check current pricing in the Sense dashboard.

---

## What happens when Sense credits run out?

When Sense credits are exhausted:
1. API calls start failing (return error response)
2. Your systems relying on Sense will not receive predictions
3. Recharge credits immediately to resume
4. Set up credit alerts to avoid running out

---

## Is there a discount for high-volume Sense API usage?

For high-volume API usage, Shiprocket may offer volume discounts. Contact your account manager or the Sense team to discuss pricing for large-scale API consumption.

---

## How to set up credit usage alerts in Shiprocket Sense?

Set up credit alerts in the Sense dashboard billing settings to receive notifications when credits fall below a configured threshold.
